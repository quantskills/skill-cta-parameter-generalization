# EVO 真实运行要求

本页只用于需要真实平台采集和复跑的场景，不是本地分析前提。普通使用见[入门说明](getting-started.md)，可选评分和模型审查见[评估说明](assessment.md)。

正式入口 https://www.pandaaiquant.com/evo 。账号环境内使用已有 CTA 策略和官方量化工具。先记录策略版本、平台版本、数据版本、成本和合约拼接口径，再冻结配置并导出结果。

## 平台输入

请在当前 EVO 工作区复用已有固定 CTA 机制，比较统一参数、仅训练期聚类共享参数和逐品种参数。先列出现有机制、可用商品合约、授权历史数据、费用和数据时间范围。不要立刻优化，也不要另建趋势环境。按训练品种及未参与分组品种、训练期及未来保留段分别冻结。训练期以外数据不得参与分组、标准化、选参。输出原始数据清单、策略版本、参数网格、逐日未扣费收益、手续费、滑点、成交和训练窗口特征，保存本次输入输出与运行编号。发现缺少合约拼接或成本字段时，先说明缺口并停止宣称可执行结果。

## 证据索引

每次平台运行目录保存 `input.txt`、原始输出、任务编号、平台地址、UTC 启止时间、数据与策略版本、依赖版本、错误日志、产物路径及 SHA256。敏感信息剔除后再纳入交付。

本地 `report.json` 的状态固定为平台证据待核验。不能只修改一个状态字段即称平台通过。交付前须将本地重算与 EVO 原始输出逐项比较。

如涉及模拟交易，需先冻结可支持的合约与委托规则，用期货模拟赛核验。不能支持的品种先记录等价回放范围及原因，回放结果不标为模拟赛成交。
